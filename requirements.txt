# audio-to-rag — top-level runtime dependencies.

# The Docker image installs the fully pinned requirements.lock, generated from this file:
#   uv pip compile requirements.txt --universal --python-version 3.12 -o requirements.lock
#
# Version constraints:
# - pyannote.audio 4.x is required: audio.py calls Pipeline.from_pretrained(..., token=...),
#   an argument that pyannote 3.x does not accept.
# - pyannote.audio 4.x needs torch and torchaudio >= 2.8. The last torchaudio release is 2.11,
#   which fixes torch at 2.11.
# - torchcodec (pyannote's audio decoder) must match the torch release: 0.11 pairs with torch 2.11.
